# MCP tool registry

The MCP server (`services/mcp-server`) exposes 46 tools — every one is a thin
wrapper: read Gold/feature functions, return a JSON-serialisable result. The
exact same functions power the ingestion/transforms CLIs and the REST bridge
(`services/api-gateway`), so there is one implementation of every feature, not
three. This document is generated by walking the real
`banklens_mcp.tools.TOOLS` registry and `banklens_mcp.authz.MCP_TOOL_TIERS`
directly — regenerate it (see the bottom of this file) rather than hand-editing
if the registry changes.

## Authorization tier

Every tool is tagged **viewer** (any authenticated `viewer` or `analyst` role)
or **analyst** (analyst role required — the heavier what-if simulators: stress
tests, bulk/comparison/surface variants, correlated scenarios). This is
enforced per-call inside the MCP server itself
(`services/mcp-server/src/banklens_mcp/authz.py`) against the same OPA policy
(`platform/auth/opa/policy.rego`) the REST bridge evaluates its routes
against — see `platform/auth/README.md`. `services/mcp-server/tests/test_authz.py`
fails CI if this file's tiers ever drift from the Rego source of truth.

A tool listed below as **UNTIERED** is missing from `MCP_TOOL_TIERS` entirely
right now — a real, currently-open gap (the same one `test_authz.py`'s
`test_every_tool_is_tiered` fails on), not a rendering artifact of this
generator. It means that tool has no per-call authorization enforced for it
until `MCP_TOOL_TIERS` is fixed.

## Params notation

`**name**: type` — required. `name: type` — optional. `enum(a|b|c)` — a
fixed set of allowed string values.

## Tools

### `list_banks` — viewer

Search/filter banks (US + EU) by name, state, country, or asset range.

Params: query: string, state: string, country: string, min_assets_b: number, max_assets_b: number, limit: integer

### `get_bank_profile` — viewer

Core Silver/Gold profile for one bank. Optional as_of (YYYYMMDD, B9) reproduces the profile as it stood on that landing date, honoring later FDIC restatements only if as_of is on or after them.

Params: **cert**: integer, as_of: string

### `get_holding_company` — viewer

B4 — this bank's holding company (real Fed NIC FR Y-9C data) with consolidated financials, or a stated reason it has none / isn't landed.

Params: **cert**: integer

### `get_bank_xray` — viewer

Feature 11 — concentration & structural risk breakdown with peer percentiles.

Params: **cert**: integer

### `get_peer_cluster` — viewer

Feature 14 — the bank's behavioral peer cluster and sample peers.

Params: **cert**: integer

### `find_ma_matches` — viewer

Feature 15 — ranked M&A partner candidates with rationale.

Params: **cert**: integer, top_n: integer

### `get_ma_pro_forma` — viewer

Feature 15 (C9) — pro-forma calculator for a proposed acquisition: combined assets/CET1/goodwill/dilution/earn-back, plus combined county HHI impact.

Params: **target_cert**: integer, **acquirer_cert**: integer, premium_to_tbv_pct: number, cost_synergies_pct_of_target_opex: number, tax_rate_pct: number

### `get_ma_weight_validation` — viewer

Feature 15 (C9) governance — whether the M&A fit-score weights actually rank real acquirers above non-acquirers, validated against real deal history.

Params: (none)

### `get_xray_forward_return_validation` — UNTIERED

Feature 14 (C10) governance — whether X-Ray-flagged banks subsequently underperform in the market, validated against landed Tiingo price history.

Params: (none)

### `get_filing_diff_population_summary` — UNTIERED

Feature 12 (C13) governance — expected false positives at the raw filing-diff z threshold across the whole population, plus a Benjamini-Hochberg FDR-controlled alternative flag set.

Params: (none)

### `get_backtest_results` — UNTIERED

Feature 17 (C14) governance — backtest of the X-Ray, deposit-flight and filing-diff signals against subsequent deposit/capital/credit deterioration and failure/exit, pooled across every landed quarter transition.

Params: (none)

### `run_stress_test` — analyst

Feature 16 — stress capital ratios under loan-loss / deposit-outflow / rate shocks.

Params: **cert**: integer, loan_loss_pct: number, deposit_outflow_pct: number, rate_shock_bps: number

### `run_stress_test_projection` — analyst

Feature 16 (C4) — multi-period (4-8 quarter) stress projection: phases the shock in and lets disclosed PPNR earn back part of each period's loss.

Params: **cert**: integer, loan_loss_pct: number, deposit_outflow_pct: number, rate_shock_bps: number, horizon_quarters: integer, phase_in: boolean, apply_ppnr_offset: boolean

### `get_liquidity_survival` — analyst

Feature 16 (C4) — quarters of on-balance-sheet liquidity survivable under a SUSTAINED quarterly deposit-outflow rate.

Params: **cert**: integer, quarterly_outflow_pct: number

### `run_segmented_stress_test` — analyst

Feature 16 (C6) — per-category loan-loss rates (construction, C&I, consumer, etc.) instead of one blended percentage, decomposed by category. Defaults to this bank's own disclosed charge-off rate per category, scaled up.

Params: **cert**: integer, category_loan_loss_pct: object, severity_multiplier: number, deposit_outflow_pct: number, rate_shock_bps: number

### `get_irrbb` — viewer

Feature 16 (C5) — EVE and 12-month NII sensitivity under a parallel rate shift and a non-parallel steepener (interest-rate risk in the banking book).

Params: **cert**: integer, parallel_shock_bps: number

### `run_correlated_stress` — analyst

Feature 16 (C4) — a single joint, correlated scenario: a rate shock triggers proportional deposit-outflow and loan-loss legs instead of three independent sliders.

Params: **cert**: integer, rate_shock_bps: number, severity: enum(mild|moderate|severe)

### `get_risk_score` — viewer

Feature 13 — deposit-flight risk score (model trained on real 2023 + 2008 failures) with drivers.

Params: **cert**: integer

### `get_risk_leaderboard` — viewer

Feature 13, population-wide — deposit-flight risk score for every landed FDIC bank, ranked descending. Optional state/cluster_label filter the population before ranking.

Params: top_n: integer, state: string, cluster_label: string

### `diff_filings` — viewer

Feature 12 — side-by-side quarter comparison for every tracked line item, flagging moves that are unusual vs the bank's own history.

Params: **cert**: integer, quarter_a: string, quarter_b: string

### `get_bank_trends` — viewer

One bank's headline Gold metrics across every landed quarter, oldest first — real QoQ trajectories for earnings, credit, funding and capital.

Params: **cert**: integer

### `get_bulk_bank_trends` — UNTIERED

E10 — the SAME per-quarter trajectory get_bank_trends returns, for a whole peer set at once (up to 40 certs), so /trends' small-multiples view can render every bank's line without N sequential requests.

Params: **certs**: array

### `get_population_trend_sparklines` — viewer

E12 — batched trailing-quarter series (last 8 quarters, up to 2500 certs) for a sparkline column next to an already-rendered population table (screener/earnings/credit/funding), one request for the whole table.

Params: **certs**: array, **metrics**: array

### `get_quarterly_briefing` — viewer

Population-wide 'what changed this quarter': population churn, biggest movers, behavioral-cluster migrations, and risk-leaderboard entrants vs the prior landed quarter.

Params: top_n: integer

### `compare_banks` — viewer

Side-by-side comparison of banks across chosen metrics.

Params: **certs**: array, metrics: array

### `get_population_metrics` — viewer

One named metric group (earnings, credit, funding, capital, concentration) across the whole population, with peer percentiles.

Params: **group**: enum(capital|concentration|credit|earnings|funding), limit: integer, sort_by: string, descending: boolean

### `get_percentile_heatmap` — viewer

Bank x metric percentile matrix (top N by a sort metric, default assets) — cells are percentile ranks, not raw values.

Params: top_n: integer, sort_by: string, metrics: array

### `get_asset_treemap` — viewer

Every bank sized by assets, grouped by behavioral cluster, state or country (the only grouping that produces a genuine pan-European view), with X-Ray risk severity for client-side coloring.

Params: group_by: enum(peer_cluster_label|state|country)

### `get_metric_distribution` — viewer

Histogram, order statistics and disclosed data-quality exclusions for one Gold metric across the population.

Params: **metric**: string, bins: integer

### `get_price_candles` — viewer

Real EOD OHLCV candlestick data for a bank's crosswalk-matched ticker (needs scripts/land_market_data.ps1 to have landed it first).

Params: **cert**: integer, limit_days: integer

### `get_market_snapshot` — viewer

Latest price, 1-day change, 30-day realized volatility, 52-week range.

Params: **cert**: integer

### `get_market_coverage` — viewer

How many crosswalk-matched tickers are actually landed vs eligible right now, and how stale the oldest landed bar is.

Params: (none)

### `get_market_overview` — viewer

E2 — cross-bank market view for a peer set or the top-N largest banks: rebased relative-performance series, a returns/volatility scatter, a pairwise return-correlation matrix, and a per-bank metrics table (beta vs an equal-weighted peer basket, realized volatility vs peer median, max drawdown, tangible book value), computed from real landed Tiingo candles + Gold fundamentals. Discloses how many of the requested banks actually have landed price data rather than silently showing only those that do. G3: per-bank price series are omitted (see performance_series_note) once more than one bank has landed price data — Tiingo is licensed redistributable=false; the aggregate analytics are unaffected.

Params: certs: array, top_n: integer, window_days: integer

### `get_data_freshness` — viewer

B10 — per-source landing vintage (fetch timestamp, record count, expected next publication) for every registered data source.

Params: (none)

### `get_metric_lineage` — UNTIERED

G9 — provenance for one bank's metric: the Gold function/formula that computed it, the Silver/FDIC source field(s) and raw values, and the originating Bronze partition path, checksum and fetch timestamp. Covers the FDIC capital/financial fields feeding get_risk_score, not the full Gold schema.

Params: **cert**: integer, **metric**: string, quarter: string

### `get_macro_data` — viewer

B5 — landed FRED macro series (Treasury yield curve, Fed funds, unemployment, CRE price index).

Params: (none)

### `get_cluster_diagnostics` — viewer

Feature 14 governance — silhouette-by-k evidence for the behavioral clustering, cluster centroids, and where size-based 'conventional' peer groups disagree with actual balance-sheet behavior.

Params: (none)

### `get_model_card` — viewer

Feature 13 governance — deposit-flight model coefficients, AUC, leave-one-out backtest against both real crises, documented exclusions (incl. Washington Mutual), and per-bank driver contributions for the live population.

Params: (none)

### `get_county_concentration` — viewer

Feature 15 — real county-level deposit HHI over the full ~4,431-cert SOD universe, against the Fed's bank-merger screening threshold (HHI >= 1800).

Params: state: string, top_n: integer

### `get_branch_map` — viewer

Feature 15 — every landed branch's real lat/lon, deposits and county, for a hand-rolled US branch map (contiguous states only).

Params: state: string

### `get_ma_network` — viewer

Feature 15 — force-graph nodes/edges of the largest banks and their top M&A-fit partners, colored by behavioral cluster.

Params: top_n: integer

### `run_bulk_stress_test` — analyst

Feature 16, cross-bank — the same shock applied to a named list of banks (a cluster, watchlist, or top-N slice) at once.

Params: **certs**: array, loan_loss_pct: number, deposit_outflow_pct: number, rate_shock_bps: number

### `run_stress_surface` — analyst

Feature 16 (E3) — stressed CET1 across a (deposit_outflow x rate_shock) grid for one bank, loan_loss_pct held fixed. Powers the Stress Lab's CET1 surface heatmap, contoured against the real regulatory CET1 minimum.

Params: **cert**: integer, loan_loss_pct: number, deposit_outflow_max_pct: number, rate_shock_max_bps: number, steps: integer

### `run_stress_comparison` — analyst

Feature 16 — the same shock priced two ways on one bank: linear-duration approximation vs a real QuantLib DCF re-price.

Params: **cert**: integer, loan_loss_pct: number, deposit_outflow_pct: number, rate_shock_bps: number

### `search_filings_text` — viewer

Feature 17 — semantic search over landed SEC 10-K Item 1A risk-factor text (pgvector cosine similarity). Cite the returned text exactly, not a paraphrase.

Params: **query**: string, top_n: integer

### `get_filings_coverage` — viewer

Feature 17 — how many filers/chunks are actually landed and searchable right now, by extraction confidence.

Params: (none)
