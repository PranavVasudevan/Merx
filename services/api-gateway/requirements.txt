# Pinned + hashed for reproducible builds (F14). Installed with
# `pip install --require-hashes -r requirements.txt` in both the Dockerfile
# and CI, so the same commit always produces the same dependency set.
# --require-hashes demands every package actually installed be listed here
# with a hash — direct AND transitive — so this is the full closure, not
# just the five packages the bridge imports by name.
#
# Direct:
#   duckdb        — banklens_mcp.data imports it unconditionally (Gold-layer
#                   SQL engine backing list_banks); crashes at import time
#                   without it.
#   prometheus-client — bridge_server.py's /metrics endpoint.
#   gunicorn      — BANKLENS_SERVER=prod transport (bridge_server.wsgi_app).
#   reportlab     — banklens_mcp.tearsheet's per-bank PDF export (D1).
#   PyJWT[crypto] — auth.py's `import jwt` / `PyJWKClient`, imported
#                   unconditionally by bridge_server.py at module load
#                   (`import auth`) regardless of BANKLENS_AUTH_ENABLED.
#                   `[crypto]` (-> cryptography) is required at runtime:
#                   auth.py verifies with RS256 (jwt.decode(...,
#                   algorithms=["RS256"])), which PyJWT can only do with the
#                   cryptography backend installed. Both PyJWT and cryptography
#                   were missing from the Dockerfile entirely before F14 — the
#                   built image crashed on container start with
#                   ModuleNotFoundError: No module named 'jwt'.
#
# Transitive (pulled in by the above; pinned explicitly so `--require-hashes`
# has a hash for every wheel pip actually installs):
#   cryptography -> cffi -> pycparser
#   gunicorn -> packaging
#   reportlab -> charset-normalizer, pillow
#
# Regenerate in a clean venv after bumping a direct pin:
#   pip install "PyJWT[crypto]==<v>" "duckdb==<v>" "prometheus-client==<v>" \
#     "gunicorn==<v>" "reportlab==<v>"
#   pip freeze   # <- the new full closure
#   # then, per package, for the CI target (linux/x86_64, cp313):
#   pip download --no-deps -d /tmp/whl "<pkg>==<v>" \
#     --platform manylinux_2_28_x86_64 --python-version 3.13 \
#     --implementation cp --abi cp313 --only-binary=:all:
#   pip hash /tmp/whl/*.whl
